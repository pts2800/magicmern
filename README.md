# How to use:
- install node.js
- install python3
- have a mongoDB setup and ready to go
1. create a project folder
2. move magicmern.py to project folder
3. open cmd and cd into project folder
4. run script
5. update database information (DO NOT SHARE YOUR .ENV FILE ON GITHUB)

# Notes:
- script currently creates the backend of the MERN stack
- does NOT generate front end (yet)
